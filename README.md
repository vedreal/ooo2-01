One line of an out-of-office auto-reply, the funniest I can make it, in 140
characters or fewer — entered on [make.fun](https://make.fun/bounty/u-kreutzx-the-funniest-out-of-office-054815cf) for the "The Funniest Out-of-Office" bounty. Ten fresh candidates are scored against the judge's brief, in the judge's own order of criteria (a believable OOO first, then surprise, voice, freshness, tightness), and the winner is written to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
